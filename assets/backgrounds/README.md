# Backgrounds locais

Coloque aqui somente vídeos próprios ou com licença comercial explícita:

- `satisfying/`: massinha, fabricação, cortes e loops satisfatórios;
- `gameplay/`: gameplay gravado por você ou licenciado;
- `technology/` e `history/`: B-roll temático licenciado.

Formatos aceitos: MP4, MOV, MKV e WebM. O pipeline escolhe offsets diferentes,
recorta para 9:16 e usa esses vídeos como fallback ou fundo de imagens relacionadas.
